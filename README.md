# Interview preflight

This checks that the environment we'll use for your interview works on your
computer. It takes about 3 minutes, and the real exercise is not in here.

1. Click **Code → Codespaces → Create codespace on main** (use Chrome or Edge).
   Wait for VS Code to open in the browser (1-2 minutes the first time). If it asks
   whether you trust the folder, click **Trust Folder & Continue**.
2. In the terminal at the bottom, run:

   ```
   python hello.py
   ```

   You should see "Your environment works."
3. Check that your AI tools work here:
   - **Claude Code** and **Codex** are installed, both in the terminal (`claude`,
     `codex`) and as sidebar panels. Here you log in with your own account; on
     interview day we provide access.
   - **GitHub Copilot** works if your GitHub account has it (Copilot Free is fine).
   - Other assistants that run in a terminal or a browser tab are fine too.
4. Close the tab. The codespace stops on its own. You can delete it from
   https://github.com/codespaces.

If anything doesn't work, reply to our email. We'd rather fix it now than
during the interview.
